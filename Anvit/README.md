# SPIRE_ZK Compilation and Setup Instructions

## Overview

This repository contains CUDA-enabled implementations related to SPIRE's Zero-Knowledge (ZK) cryptographic projects. Due to CUDA dependencies, compiling and running the code requires a CUDA-enabled environment such as the GMU lab machines.

---

## Prerequisites

- Access to a CUDA-capable GPU machine (e.g., GMU CUDA lab machines).
- CUDA Toolkit installed and properly configured.
- CMake installed.
- Make utility installed.
- Git installed.
